# Catdana Store - Vintage Shop

Landing page for Catdana Store, a vintage shop that sells analog cameras, vintage clothes, vinyl, and other goods.

## Features
- Promo banner at the top that can be closed
- Search bar to find products by name
- Product grid with images (camera, clothes, vinyl)
- Navigation: About, Careers, History, Services, Projects, Blog
- How to Shop page (cara_belanja.html)
- Chat Admin button
- Responsive layout using Tailwind CSS

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- JavaScript

## Files
- index.html - Main page
- cara_belanja.html - How to shop page

## How to Use
1. Open index.html with Live Server or double click
2. Type product name in search bar, example: kamera analog
3. Click Cari Barang button to filter products
4. Click How to Shop to see how to order
